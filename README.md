# KPI Dashboard Starter (Penpot plugin)

Creates four editable boards in the current Penpot file: a dashboard start screen and a KPI detail screen, each in a 30-day and a 7-day version, with click interactions already wired up.
The example KPI ("Snelheid route") shows a headline number, old-vs-pilot comparison, line chart, bar chart and takeaway. Dashed slots on the start screen are for your team's KPI cards.

Install by URL: Penpot > Ctrl+Alt+P > paste the URL of manifest.json > Install.
Host all files of this folder (manifest.json, plugin.js, icon.png) on a static host with CORS enabled, for example GitHub Pages.
